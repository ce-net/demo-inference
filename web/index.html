How it works. The model is Qwen2.5-0.5B-Instruct (Apache-2.0), served by llama.cpp on each device and wrapped as the cell infer.generate@1. This page holds a short grant (a fresh ed25519 key and a signed capability chain, with a token budget in it) and speaks the cells' own wire protocol over one WebSocket. place.near@1 ranks the devices that hold the cell by the round trip this browser measured to each (net.rtt@1), the mesh hop to it (mesh.bench) and the free room it reports. "Take it away" unregisters the cell on that device for 20 seconds; nothing else on the device stops. The answer that was streaming ends with moved, and this page sends the text so far to the next device, which continues it. The code panel is generated by client.gen@1 from the cell's own api.
